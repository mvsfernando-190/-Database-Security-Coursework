\# Database Security – Secure MySQL Database Design and Implementation



\## Project Overview



This project focuses on the design, implementation, and security of a MySQL database infrastructure for a medium-sized financial services organization.



The coursework explores database security mechanisms, access control models, threat mitigation, high availability, read scalability, and independent security auditing.



\*\*Institution:\*\* National Institute of Business Management (NIBM)  

\*\*School:\*\* School of Computing and Engineering  

\*\*Course:\*\* Higher National Diploma in Network Engineering  

\*\*Batch:\*\* HNDNE 25.2F  

\*\*Module:\*\* Database Security  

\*\*Assessment:\*\* Coursework 01 – Group Project



\## Project Objectives



\- Design a secure relational database using MySQL.

\- Apply the CIA Triad (Confidentiality, Integrity, and Availability).

\- Implement MySQL authentication and access security.

\- Configure DAC, RBAC, and MAC access control models.

\- Demonstrate and mitigate SQL Injection attacks.

\- Implement MySQL Primary-Replica replication.

\- Configure HAProxy for database load balancing and high availability.

\- Conduct an independent database security audit based on ISO 27001.

\## Key Implementations



\### 1. Secure Database Design

\- Relational database design.

\- Primary and foreign key relationships.

\- Constraints and data validation.

\- CIA Triad security mapping.



\### 2. Authentication and Access Security

\- MySQL Native Password Authentication.

\- Caching SHA-2 Authentication.

\- PAM and Kerberos authentication concepts.

\- Database security hardening.



\### 3. Database Access Control

\- Discretionary Access Control (DAC).

\- Role-Based Access Control (RBAC).

\- Mandatory Access Control (MAC) simulation.

\- Role and privilege management.



\### 4. Threat Identification and Mitigation

\- SQL Injection vulnerability demonstration.

\- Attack analysis and business impact.

\- Least privilege implementation.

\- Password hashing.



\### 5. High Availability and Read Scalability

\- MySQL Primary-Replica replication.

\- Replication testing.

\- HAProxy configuration.

\- Database load balancing and failover concepts.



\### 6. Security Audit and Compliance

\- Database privilege auditing.

\- Authentication and firewall reviews.

\- Replication security assessment.

\- HAProxy exposure assessment.

\- ISO 27001-based audit findings and recommendations.
