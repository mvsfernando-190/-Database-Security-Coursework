# Database Security – Secure MySQL Database Design and Implementation

## Project Overview

This project was completed as part of the Database Security coursework for the Higher Diploma in Network Engineering at NIBM.

The project focuses on designing and implementing a secure MySQL database environment, applying database security principles, access control mechanisms, authentication methods, and high availability concepts.

## Academic Information

- **Institution:** NIBM
- **Programme:** Higher Diploma in Network Engineering
- **Batch:** HNDNE 25.2F
- **Module:** Database Security
- **Academic Year:** 2026
- **Project Type:** Group Coursework

## Project Objectives

- Understand the CIA Triad in database security.
- Explore MySQL authentication mechanisms.
- Apply Discretionary, Mandatory, and Role-Based Access Control.
- Identify and prevent SQL injection attacks.
- Understand MySQL primary-replica replication.
- Explore HAProxy for database load balancing.
- Evaluate database security using ISO/IEC 27001 principles.

## Key Areas Covered

### 1. Database Security Fundamentals
- Confidentiality, Integrity, and Availability (CIA Triad).
- Database security principles and threats.

### 2. Authentication and Access Control
- MySQL authentication mechanisms.
- DAC, MAC, and RBAC access control models.
- User privileges and permissions.

### 3. SQL Injection
- Understanding SQL injection vulnerabilities.
- Attack scenarios and prevention techniques.
- Secure query handling.

### 4. High Availability and Load Balancing
- MySQL primary-replica replication.
- HAProxy architecture and load balancing concepts.
- Database availability and reliability.

### 5. Security Audit
- ISO/IEC 27001 security controls.
- Database security assessment.
- Security recommendations and improvements.
